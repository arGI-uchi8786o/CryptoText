# Writer Your Manifest

Python скрипт для генерации, шифрования и управления безопасными манифестами. Манифесты - это зашифрованные контейнеры для текста или данных файлов, использующие AES-256-GCM шифрование.

## Возможности

- **Генерация Манифестов**: Шифрование текста или содержимого файла в безопасный манифест.
- **Декодирование Манифестов**: Расшифровка и отображение содержимого манифеста.
- **Упаковка Манифестов**: Сжатие директорий манифестов в ZIP архивы.
- **Метаданные**: Опциональное логирование метаданных (время, автор, информация о системе и т.д.).
- **Режим Отладки**: Включение детального логирования для устранения неисправностей.
- **Поддержка Файлов**: Шифрование файлов напрямую с флагом `--this-is-a-file`.

## Требования

- Python 3.x
- Библиотека `cryptography`: Установите с `pip install cryptography`
- Библиотека `colorama`: Установите с `pip install colorama`

## Установка

1. Убедитесь, что Python 3.x установлен.
2. Установите зависимости:
   ```
   pip install cryptography colorama
   ```
3. Скачайте или клонируйте скрипт `writer_Your_manifest.py`.

## Использование

Запустите скрипт из командной строки:

```
python writer_Your_manifest.py [команда] [аргументы] [опции]
```

### Команды

- `gen [имя] [текст]`: Генерация нового манифеста.
  - `[имя]`: Имя манифеста.
  - `[текст]`: Текстовое содержимое для шифрования.
  - Опции:
    - `--this-is-a-file [путь_к_файлу]`: Шифрование файла вместо текста.
    - `--debug-mode-on`: Включение вывода отладки.
    - `--metadata-remove`: Пропуск генерации метаданных.

- `ungen [имя]`: Декодирование и отображение содержимого манифеста.
  - `[имя]`: Имя манифеста для декодирования.

- `pack [имя]`: Упаковка директории манифеста в ZIP файл.
  - `[имя]`: Имя манифеста для упаковки.

- `help` или `--help` или `-h`: Отображение информации об использовании.

### Примеры

1. **Генерация манифеста с текстом:**
   ```
   python writer_Your_manifest.py gen mymanifest "Это мое секретное сообщение"
   ```

2. **Генерация манифеста из файла:**
   ```
   python writer_Your_manifest.py gen mymanifest /path/to/file.txt --this-is-a-file
   ```

3. **Декодирование манифеста:**
   ```
   python writer_Your_manifest.py ungen mymanifest
   ```

4. **Упаковка манифеста:**
   ```
   python writer_Your_manifest.py pack mymanifest
   ```

5. **Генерация с режимом отладки и без метаданных:**
   ```
   python writer_Your_manifest.py gen mymanifest "Секретный текст" --debug-mode-on --metadata-remove
   ```

### Структура Выхода

При генерации манифеста создается директория `MANIFEST_[имя]`, содержащая:
- `main_manifest.bin`: Зашифрованное содержимое.
- `Dec_info.txt`: Ключи расшифровки (ключ, nonce, tag).
- `metadata.txt`: Опциональные метаданные (если не удалены).
- `Debug_decrypted_manifest(DeleteMe).txt`: Файл отладки (если включен режим отладки).

### Замечания по Безопасности

- Манифесты используют AES-256-GCM для шифрования.
- Ключи расшифровки хранятся в `Dec_info.txt` – держите это в безопасности.
- Для бинарных файлов используйте внешние архиваторы, такие как ZIP с паролями.
- Режим отладки раскрывает расшифрованное содержимое – используйте осторожно.
